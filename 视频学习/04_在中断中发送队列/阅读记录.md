# 04 在中断中发送队列

## 纪要覆盖的完整内容

1. **DMA 中断里把“转换完成”告诉线程 A**
   - 约定线程 A 为 `StartDefaultTask`。
   - 中断中用队列发送完成标志；数据变量需跨函数使用，因此从局部变量改为文件域变量（`q_data1`），定义移到 USER CODE 变量区，原有编译错误消失。

2. **中断中必须用 `xQueueSendFromISR`**
   - 宏定义完成标志：`DMA_ADC_CPLT`（如 0xA1A1A1）。
   - 中断里发送该标志，不等待。
   - 使用 `xHigherPriorityTaskWoken` 管理任务切换；由 `portYIELD_FROM_ISR` 置位 PendSV，退出中断后再切换，避免在 ISR 内直接切换导致卡死。

3. **调试问题**
   - 队列创建顺序错误：中断触发时队列还没创建，导致失败；把队列创建移到启动 ADC/DMA 之前。
   - 变量类型不匹配告警：修正有符号/无符号赋值方式。

## 技术核对

- `xQueueSendFromISR(queue, &item, &xHigherPriorityTaskWoken)`：第三个参数是**唤醒标志的地址**，不是超时。
- 必须在 ISR 末尾调用 `portYIELD_FROM_ISR(xHigherPriorityTaskWoken)`；只置 true 而不调用，任务不会立即切换。
- 全局变量解决“跨函数可见”，但也引入共享访问问题；本节尚未涉及同步保护。
- 队列必须在可能产生中断之前创建好。
