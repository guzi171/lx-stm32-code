## 学习使用建议

1. 先按 `视频学习/01`、`02` 的顺序，对照 `参考工程/00`～`02` 看代码差异。
2. 自己动手时从 `00_初始工程` 开始，不要直接抄 V6。
3. 每完成一步，用 `03`～`06` 的记录核对预期结果。
4. 15-1 的终点是“发现没有同步的弊端”，不要提前把 15-2 的互斥量方案塞进来。
