# STM32 课程代码仓库

本仓库按课程阶段和作业拆分分支。`master` 用于维护仓库说明与分支总览；各作业工程保存在对应的作业分支中。

## 分支命名规则

作业分支统一使用以下格式：

```text
t阶段号-分支序号-英文主题
```

例如：`t01-01-led_initial`

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| `t01` | 第 1 个课程阶段 | `t01` |
| `01` | 该阶段的第 1 个作业 | `01` |
| `led_initial` | 作业主题，使用小写英文和下划线 | 裸机 LED |

## 分支简述

| 分支 | 内容 |
| --- | --- |
| `master` | 仓库主分支，维护分支说明和课程作业总览。 |
| `t01-01-led_initial` | 第 1 阶段第 1 个作业：STM32 裸机 LED 点亮。 |
| `t02-01-project_template_en` | 第 2 阶段第 1 个作业：英文版 STM32 工程模板。 |
| `t02-02-project_template_cn` | 第 2 阶段第 2 个作业：中文版 STM32 工程模板。 |
| `t03-01-freertos_printf` | 第 3 阶段第 1 个作业：FreeRTOS 环境下的 `printf` 输出。 |

## 使用说明

- 查看某个作业前，先切换到对应分支，例如：`git switch t01-01-led_initial`。
- 每个作业分支只保存该作业相关的源码、工程配置和说明文档。
